# Trouser Product Assets

Place real trouser product images in this directory using this structure:

```text
public/products/trousers/
  TR-REAL-001/
    main.jpg
    thumbnail.jpg
  TR-REAL-002/
    main.jpg
    thumbnail.jpg
  TR-REAL-003/
    main.jpg
    thumbnail.jpg
```

Do not add trouser entries to `lib/products.ts` until the referenced image files exist.
